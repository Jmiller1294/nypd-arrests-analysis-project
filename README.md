# 🗽 NYPD Arrests Data Analysis Project

## 1. Project Overview
This project analyzes NYPD Arrests(2021) data to uncover trends in crime, demographics, and geography across New York City. The goal is to demonstrate skills in data cleaning, exploratory data analysis (EDA), and visualization using Python, Pandas, and Tableau.

**Tools Used:**   
- Python (pandas, matplotlib)  
- Tableau (charts & heatmaps)  
- Jupyter Notebooks: Data cleaning, feature engineering, EDA
- Git/GitHub: Version control and publishing  

## 2. Data Sources
- **Dataset:** [NYC OPEN DATA - NYPD ARREST DATA](https://data.cityofnewyork.us/Public-Safety/NYPD-Arrest-Data-Year-to-Date-/uip8-fykc/about_data)  
- **COVID Dataset**: [DEPT OF HEALTH - COVID CASE SURVEILLANCE DATA](https://catalog.data.gov/dataset/covid-19-case-surveillance-public-use-data-with-geography-0605b)  
- **Format:** CSV file

## 4. Key Insights
- Most Arrests: Most arrests occured in Brooklyn and Manhattan.
- Likely Demographic: Men within age group of 25-44 were arrested the most.
- Monthly Arrests Trends: Arrests were the lowest in April, but peaked in October.
- COVID Influence: The steady rise in arrests after April was similar to the rise in COVID-19 cases after restrictions were lifted. 

---

## 5. Recommendations
- Balance Enforcement: Have more NYPD officers deployed in Manhattan and Brooklyn due to higher crime occurrences within the large city area. 
- Support the 25–44 Age Group: Provide mental health services, job training, and rehabilitation centers.
- Seasonal Crime Prevention: Arrests are high during Summer and Fall, therefore we should strengthen community policing, youth engagement, and outreach efforts during these times. 
- Gender-Responsive Programs: Since men ages 25-44 are arrested most for violent crimes and property crimes, we should expand mentorship opportunities, support groups, rehabilitation, and violence-prevention initiatives tailored for young men.
