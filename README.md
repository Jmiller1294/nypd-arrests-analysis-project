🗽 NYPD Arrests Data Analysis

📌 Overview

Analyzed NYPD Arrests data (2021) to uncover crime, demographic, and neighborhood-level trends across NYC.
Project demonstrates data cleaning, EDA, geospatial analysis, and dashboarding skills using Python and Tableau.

⚙️ Tools & Skills

Python (Pandas, GeoPandas, Matplotlib)

Tableau Public (interactive dashboards & heatmaps)

Jupyter Notebooks (data cleaning & exploration)

Git/GitHub (portfolio publishing)

🔑 Highlights

Cleaned and standardized raw arrest data (100k+ records).

Engineered new features (e.g., month names for seasonal analysis).

Explored arrest patterns by borough, offense type, and demographics.

Joined arrests dataset with NYC neighborhood shapefiles for spatial insights.

Built an interactive Tableau heatmap showing arrests by neighborhood.
